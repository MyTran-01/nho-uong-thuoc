# Nhớ Thuốc

App iOS nhắc uống thuốc cho người hay quên.

## Cấu trúc

- `app/` — mã nguồn iOS (SwiftUI, Xcode project `NhoThuoc.xcodeproj`)
- `docs/` — tài liệu sản phẩm: PRD, user flow, design system, ảnh review
- `output/` — ảnh xuất ra (icon app, thử nghiệm giao diện)

## Chạy app

Mở `app/NhoThuoc.xcodeproj` bằng Xcode, chọn simulator iPhone rồi bấm Run.
